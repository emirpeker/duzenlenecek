# Programming Practice

A collection of programming exercises, university coursework,
and small software projects developed while learning different
languages and technologies.

## Repository Structure

| Directory | Contents |
| --- | --- |
| [Python](./python/) | Python fundamentals, OOP, SQLite and coursework |
| [Java](./java/) | Java fundamentals, OOP, JavaFX and assignments |
| [C / C++](./c-cpp/) | Algorithms, arrays, loops and programming exercises |
| [C#](./csharp/) | .NET fundamentals, LINQ and ASP.NET Core |

## Selected Projects and Exercises

- **Rentify Course Project** - PyQt6 and MySQL-based car rental
  management application.
- **Vehicle Rental CLI** - SQLite-based vehicle rental exercise.
- **Product API** - ASP.NET Core Web API with in-memory product data.
- **CV Creator Prototype** - JavaFX application prototype.

## Notes

- This repository is primarily an educational code archive.
- Examples are independent and may require different development
  environments or dependencies.
- Not all exercises have been tested with current software versions.
- Build outputs, local databases, personal documents, and submission
  archives are excluded from the maintained source collection.

## Purpose

Documenting programming progress and keeping coursework and
technical exercises organized and accessible.
