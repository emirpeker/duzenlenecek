# Java Programming Practice

Java coursework and exercises covering fundamental programming,
object-oriented design, exception handling, and JavaFX.

## Structure

- `fundamentals/` - introductory course exercises
- `exercises/` - OOP, exception handling, and other examples
- `assignments/` - university programming assignments
- `labs/` - laboratory exercises
- `gui/` - JavaFX and graphical interface experiments
- `projects/cv-creator-prototype/` - CV creator application prototype

These are educational exercises. Some projects require JavaFX,
specific JDK versions, or additional configuration.
