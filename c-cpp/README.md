# C and C++ Programming Practice

Educational exercises written in C and C++.

## Structure

- `fundamentals/btk-course/` - BTK course examples
- `fundamentals/practice/` - basic programming exercises
- `algorithms/arrays/` - arrays and matrices
- `algorithms/loops/` - loops and number problems
- `algorithms/functions/` - functions
- `algorithms/pointers/` - pointers
- `algorithms/miscellaneous/` - other algorithms
- `assignments/university/` - university coursework
- `assignments/homework-8/` - C programming assignment

These are educational exercises rather than
production-ready applications.
