# C# and .NET Programming Practice

Educational C# exercises and an ASP.NET Core Web API project.

## Structure

### Fundamentals

- `fundamentals/dotnet-basics/` - basic C# syntax and concepts
- `fundamentals/loops/` - loops
- `fundamentals/conditionals/` - conditional statements
- `fundamentals/methods/` - methods

### LINQ

- `linq/linq-basics/` - LINQ exercises
- `linq/product-filtering/` - product filtering with LINQ

### Projects

- `projects/product-api/` - ASP.NET Core product API

The Product API demonstrates HTTP endpoints and product filtering
using in-memory data rather than a production database.

Projects retain their original .NET configuration and may
require a compatible .NET SDK.
